# التوقيع الرسمي — الإذاعة المدرسية (school-radio-android)

كل إصدارات هذا التطبيق موقّعة **بنفس المفتاح** وبنفس البصمة الثابتة أدناه،
حتى يتمكن المستخدمون من **تثبيت التحديث الجديد فوق النسخة القديمة مباشرة**
دون حذف التطبيق ودون فقدان أي بيانات.

## بصمة شهادة التوقيع (SHA-256)

```
08:32:19:AA:51:F3:6D:15:70:B8:68:8B:66:7D:61:FE:49:C7:CE:67:9F:4D:74:3A:41:47:A8:09:3D:4C:64:F4
```

- الخوارزمية: SHA384withRSA، مفتاح RSA 2048-bit
- صلاحية الشهادة: 30 سنة (حتى 2056)
- الاسم المميز: CN=School Radio (الإذاعة المدرسية), O=SaidJTE, L=Casablanca, C=MA

## كيف تتحقق من ملف APK الذي حمّلته؟

على حاسوب لديه Android build-tools:

```bash
apksigner verify --print-certs SchoolRadio_vX.Y.Z.apk
```

يجب أن تطابق بصمة `SHA-256 digest` البصمة أعلاه حرفياً.

أو عبر مفتاح سكربت التحقق الجاهز في المستودع:

```bash
bash tools/verify_release.sh SchoolRadio_vX.Y.Z.apk
```

## قاعدة ذهبية

> إذا ظهرت بصمة مختلفة عن البصمة أعلاه — **لا تثبّت هذا الملف**؛
> إنه ليس إصداراً رسمياً من هذا المشروع.
