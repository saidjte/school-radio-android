المعماريات: arm64-v8a + armeabi-v7a • يعمل دون إنترنت بالكامل • التحديث فوق v0.4.0 مباشرة (نفس المفتاح — بياناتك كما هي)

عند أول تثبيت: اسمح بـ «تثبيت التطبيقات من مصدر غير معروف» لهذا المتصفح، ثم افتح الملف المحمّل. التحديثات اللاحقة ستُثبَّت فوق النسخة الحالية مباشرة دون حذف.

المزايا

  • لوحة تحكم: ساعة حية، قيد التشغيل الآن، الفقرة التالية، جدول اليوم مع حالة كل فقرة
  • مكتبة صوتية محلية: استيراد MP3/WAV عبر SAF، تصنيفات، بحث، إعادة ربط الملفات المفقودة
  • قوائم تشغيل: ترتيب، تكرار، ربط بفقرات مجدولة
  • جدولة أسبوعية دقيقة (AlarmManager) مع إعادة تهيئة تلقائية ومنع التكرار وسجل تنفيذ
  • بث مباشر «اضغط للتحدث» عبر الميكروفون إلى المكبرات بتأخير منخفض + خفض تلقائي للموسيقى
  • جديد v0.5.0: تشغيل التسجيلات ضمن الفقرات المجدولة — محتوى الفقرة: قائمة أو مقطع أو تسجيل من الأرشيف
  • جديد v0.5.0: شاشة العرض «على الهواء»: صورة الفقرة ونصها بملء الشاشة مع التقدم والساعة — للبروجكتور
  • جديد v0.5.0: صور ونصوص لكل فقرة (تظهر في شاشة العرض والبطاقات) + جدولة سريعة من أرشيف التسجيلات
  • جديد v0.5.0: إصلاح الطريق المسدود في الجدولة (زر «فقرة مجدولة» يفتح إنشاء الجدول تلقائياً)
  • نظام تصميم كامل — ألوان M3، طباعة عربية مضبوطة، ألوان حالة تتكيف مع الداكن (v0.4.0)
  • لوحة تحكم: تحية زمنية، بطاقة بطل، عدّاد حي للفقرة التالية، نبضات لمس (v0.4.0)
  • تسجيل البث الحي أثناءه + فقرات تحضيرية — AAC 128kbps في الأرشيف المحلي (v0.3.0)
  • الأدوار: مشرف / معلم / طالب — ببوابات على الجدولة والتسجيلات (v0.3.0)
  • مشغل خلفي (Media3) بإشعار تحكم وتخطي تلقائي للملفات المعطوبة
  • نسخ احتياطي واستعادة عبر SAF مع فحص سلامة ونسخة أمان
  • واجهة عربية RTL كاملة — Material 3 — يعمل دون إنترنت بالكامل
